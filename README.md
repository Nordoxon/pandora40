# Site Watcher Bot

Вот промпт, который можно прямо вставить в Lovable (или аналогичный AI-генератор проекта). Я сделал его максимально конкретным, чтобы сразу получить рабочий MVP без лишних догадок:



---



**ПРОМПТ:**



Создай минимальный, но надёжный проект на Python, который выполняет мониторинг изменений на веб-странице и отправляет уведомления в Telegram.



### 🎯 Цель проекта



Нужно отслеживать любые изменения на главной странице сайта (HTML целиком) и сразу уведомлять меня через Telegram-бота.



---



### ⚙️ Основные требования



1. **Проверка сайта**



   * Делать HTTP-запрос к указанному URL каждую минуту

   * Сравнивать текущий HTML страницы с предыдущим состоянием

   * Если есть ЛЮБЫЕ изменения (даже минимальные) — считать это изменением



2. **Логика сравнения**



   * Сохранять предыдущую версию HTML (в файл или память)

   * При первом запуске просто сохранить состояние без уведомления

   * Начиная со второго запроса — сравнивать

   * Можно использовать:



     * hash (например SHA256), или

     * прямое сравнение строк



3. **Telegram-уведомления**



   * Использовать Telegram Bot API

   * При обнаружении изменений отправлять сообщение:



     ```

     ⚠️ Обнаружены изменения на сайте!

     URL: <ссылка>

     Время: <текущее время>

     ```

   * Токен бота и chat_id должны задаваться через переменные окружения



4. **Надёжность**



   * Обрабатывать ошибки:



     * сайт недоступен

     * таймаут

     * ошибки Telegram API

   * При ошибках не падать, а логировать и продолжать работу



5. **Конфигурация**



   * Все параметры вынести в config:



     * URL сайта

     * интервал проверки (по умолчанию 60 секунд)

     * Telegram token

     * chat_id



6. **Логирование**



   * Писать логи в консоль:



     * успешные проверки

     * изменения

     * ошибки



---



### 🧱 Технические требования



* Язык: Python 3.10+

* Использовать:



  * requests (или httpx)

  * hashlib

  * time / schedule / asyncio (на выбор)

* Структура проекта:



  ```

  /project

    main.py

    config.py

    watcher.py

    notifier.py

    requirements.txt

  ```



---



### 🚀 Поведение программы



1. Запускается

2. Делает первый запрос → сохраняет HTML

3. Каждую минуту:



   * запрашивает страницу

   * сравнивает с предыдущей

   * если есть изменения → отправляет Telegram сообщение
